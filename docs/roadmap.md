# Направления развития

Сохраняем сбор исходной речи и текущие голоса персонажей. Первый клон после 60 с
чистой речи, обновление после 160 с с отбором лучших образцов. Импорт готовых образцов
в чужой аккаунт реализован отдельно и не изменяет текущую запись.

Дальнейшие эксперименты:

- Эмоции: сначала локальная модель без оплаты за запросы; измерить качество и
  задержку на реальной смеси игрового звука, включать только по желанию пользователя.
- Индивидуальные профили: сравнить фиксированные фразы, совместимость параметров
  конкретного endpoint и похожесть голоса. Не менять сразу настройки всех персонажей.
- Словарь произношения: собрать реальные ошибки имён и названий, проверить русские
  замены на используемых моделях, не менять отображаемые субтитры.
- ТВ: исследовать фильтр телевизора с отдельным переключателем и проверкой
  совместимости PCM/HTTP/WebSocket; существующий режим ТВ сохраняется.
- Voice Remixing: варианты временных NPC после сравнения с исходником, без
  автоматической замены голосов сюжетных персонажей.

Эти пункты не включены в рабочий EXE автоматически.

Для установки другими людьми нужны мастер первого запуска, упаковка FFmpeg с
учётом его лицензии, проверка русского OCR Windows, пользовательский каталог данных
вместо дисков D/F, переносимые зависимости очистки и отдельный добровольный пакет
локальной модели эмоций. Основная озвучка должна запускаться без фонового обучения
и без ключа OpenAI; радиоперевод и облачный анализ подключаются отдельно.

Исходники доступны в Git отдельно от приватных образцов, записей, диагностических
журналов, ключей и рабочих исполняемых файлов. Не публикуйте пакеты записанных
голосов вместе с исходниками без отдельного решения о распространении этих данных.
