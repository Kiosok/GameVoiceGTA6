# Пакеты голосовых образцов

Пакет создаётся из текущих установленных образцов, а не из всех записей персонажа.
Экспорт сверяет хеши с активными назначениями и сохраняет только готовые WAV-файлы,
имена, длительность чистой речи и контрольные суммы. Ключи и ID аккаунта автора не
экспортируются. Сохраняйте пакеты отдельно от Git.

```powershell
work/venv/Scripts/python.exe tools/voice_pack.py export --installations ПУТЬ_К_БАНКУ/installations --overlay "$env:LOCALAPPDATA/GameVoice/automatic-voices.json" --output work/private-voice-pack
```

На компьютере получателя сохраните его собственный ключ ElevenLabs в приложении,
закройте приложение и проверьте пакет:

```powershell
work/venv/Scripts/python.exe tools/voice_pack.py import ПАПКА_ПАКЕТА
```

Эта команда локальная. Для загрузки образцов и установки голосов нужен явный запуск:

```powershell
work/venv/Scripts/python.exe tools/voice_pack.py import ПАПКА_ПАКЕТА --upload --confirm-rights --install
```

`--confirm-rights` подтверждает право загружать и клонировать предоставленные голоса.
Импорт требует User Read, Voices Read/Write, доступ к IVC и свободные голосовые слоты.
Он проверяет аккаунт/workspace и квоту до загрузки. Проверочного платного TTS нет.
Скрипт не покупает слоты, не удаляет и не редактирует существующие голоса.

Для каждой пары аккаунт/workspace и пакета ведётся отдельный локальный журнал.
Повторный запуск использует уже созданные голоса. Если ответ POST потерян, скрипт
ищет голос по уникальной метке; без однозначного результата останавливается вместо
повторного создания. После явного отклонения повтор допускается только с
`--retry-rejected`. Требование верификации ElevenLabs не обходится: назначение
приостанавливается до подтверждения готовности голоса.

Установка назначений сохраняет резервную копию, остальные голоса, темп и настройки.
При свежем heartbeat работающего приложения установка запрещена: сначала закройте
программу и подождите 30 секунд. Не запускайте её одновременно с установкой.

Текущая реализация — скрипт для разработки. Для будущего установщика этот же процесс
можно обернуть в один мастер с выбором пакета и показом доступных слотов.

Официальный API: https://elevenlabs.io/docs/api-reference/voices/ivc/create
