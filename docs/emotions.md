# Эксперимент передачи эмоций

Рабочая озвучка не изменена. Платные измерения не запускались: пользователь выбрал
не расходовать токены. Никакого автоматического анализа через OpenAI нет.

`emotion_probe.py` содержит отдельную исследовательскую функцию: ограниченный
аудиопрефикс → классификация подачи → фиксированный тег v4 Turbo. Это не доказанная
функция распознавания эмоций в игре. Свободный ответ модели не попадает в TTS.

`tools/benchmark_emotions.py` по умолчанию лишь показывает число будущих запросов.
Только явный `--run` выполняет платный тест. Приватный JSON имеет вид:

```json
{"samples": [{"character": "Персонаж", "path": "исходный-английский-фрагмент.wav", "voice_id": "ID_ИЗ_СВОЕГО_АККАУНТА", "text": "Русская реплика."}]}
```

```powershell
work/venv/Scripts/python.exe tools/benchmark_emotions.py work/private-samples.json --output work/private-emotion-results
```

Методика для возможного будущего теста: 3 сохранённых фрагмента по 1,2 секунды,
3 анализа, 3 исключённых прогрева голоса и 6 пар «обычная/с тегом» с чередованием
порядка. Измеряются время анализа, первый аудиоблок и полная готовность реплики.
Звук можно сохранить только с отдельным `--save-audio`; автоматически он не играет.

Даже такой тест не измеряет задержку живого OCR и не доказывает точность эмоций.
Очищенная речь проще смеси музыки и нескольких говорящих. Для вывода о качестве
нужно сравнение на слух с оригиналом и разметка правильной подачи.

Для модели, начинающей анализ после накопления N мс исходного звука, добавочное
ожидание к моменту готовности OCR оценивается как
`max(0, N + время_анализа - прошедшее_время_до_OCR)`.
Это расчёт, а не измеренный результат. При накопленном аудио часть ожидания можно
перекрыть распознаванием субтитров.

## Локальные кандидаты без оплаты за запросы

SpeechBrain `emotion-recognition-wav2vec2-IEMOCAP` обучен на английской речи,
использует mono 16 kHz и имеет лицензию Apache-2.0. Подходит для первого локального
эксперимента с небольшим набором эмоций. Заявленная точность на IEMOCAP не равна
точности на игровых записях.

https://huggingface.co/speechbrain/emotion-recognition-wav2vec2-IEMOCAP

emotion2vec+ base — другой кандидат, около 90 млн параметров, 9 классов. Лицензия
модели отдельная: условия распространения нужно проверить перед включением в
публичный установщик.

https://huggingface.co/emotion2vec/emotion2vec_plus_base

Веса не скачивались, зависимости не устанавливались. Локальные модели пока не
встроены и их время работы на этом ПК не измерено. Их следует тестировать отдельным
процессом, чтобы не задерживать аудиоколбэк, OCR и обработку банка голосов. Нужны
нейтральная подача при низкой уверенности и ограничение времени ожидания.
