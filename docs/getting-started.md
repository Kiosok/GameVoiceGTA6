# Первый запуск на Windows

[← На главную](../README.md)

Это инструкция для текущей беты из исходников. Готовый установщик и мастер первого
запуска ещё разрабатываются. Для новой карты может понадобиться изменение кода.

## 1. Подготовьте компьютер

- Windows 10/11 x64 и **Python 3.11 x64** с сайта [python.org](https://www.python.org/downloads/windows/).
- **FFmpeg** в PATH: загрузки и сборки доступны на [ffmpeg.org](https://ffmpeg.org/download.html).
  Откройте новый PowerShell и выполните `ffmpeg -version`: должна появиться информация о версии.
- Русский компонент распознавания текста Windows. В параметрах Windows откройте
  «Время и язык» → «Язык и регион», добавьте русский язык и его компонент OCR,
  если он доступен отдельно. В разных версиях Windows названия пунктов отличаются.
- Подключённая по [схеме](../README.md#как-подключить) карта захвата.

Текущий захват настроен в `outputs/GameVoice/subtitle_voice.py`: `video=USB3.0 Video`,
MJPEG, 1280×720, 30 кадров/с. Выполните команду ниже, чтобы увидеть имена устройств:

```powershell
ffmpeg -hide_banner -list_devices true -f dshow -i dummy
```

FFmpeg здесь только перечисляет устройства, после чего может завершиться сообщением
об ошибке `dummy` — это ожидаемо. Если имя карты другое, текущая бета не выберет её
автоматически. Нужно адаптировать имя и проверить поддерживаемый режим захвата;
для дополнительных аудиорежимов отдельно проверяется аудиоустройство.

## 2. Скачайте исходники и зависимости

На [странице проекта](https://github.com/Kiosok/GameVoiceGTA6) нажмите **Code → Download ZIP**
и распакуйте архив. Откройте PowerShell в распакованной папке с файлом `README.md`.
Если используете Git, можно вместо ZIP выполнить `git clone https://github.com/Kiosok/GameVoiceGTA6.git`
и перейти в созданную папку.

```powershell
py -3.11 -m venv work/venv
work/venv/Scripts/python.exe -m pip install -r outputs/GameVoice/requirements-subtitles.txt
```

Окружение изолировано внутри проекта. Изменять политику выполнения PowerShell
или активировать окружение отдельной командой не требуется.

## 3. Сохраните свой ключ ElevenLabs

Создайте API-ключ в [аккаунте ElevenLabs](https://elevenlabs.io/app/settings/api-keys).
Для озвучки нужен **Text to Speech → Access**, для обновления списка голосов —
**Voices → Read**. Доступ к выбранной модели и голоса определяются вашим аккаунтом.
Синтез расходует его кредиты; подписка ChatGPT эти расходы не оплачивает.

В нынешнем окне озвучки поля для первоначального ввода ключа ещё нет. Выполните
локальную команду ниже в той же папке. На запрос `ElevenLabs API key:` вставьте свой
ключ и нажмите Enter. Символы при вводе в обычном терминале не отображаются.

```powershell
work/venv/Scripts/python.exe -c "import sys; sys.path.insert(0, 'outputs/GameVoice'); from getpass import getpass; from key_store import save_key; from elevenlabs_speech import key_path; save_key(getpass('ElevenLabs API key: '), key_path()); print('Key saved locally.')"
```

Команда **не обращается к API**. Ключ сохраняется через Windows DPAPI для текущего
пользователя в `%LOCALAPPDATA%/GameVoice/elevenlabs-key.dpapi`. Не вписывайте его в
текст команды, исходники, Issues или скриншоты. Чтобы заменить ключ, закройте
приложение, повторите команду и запустите его заново.

Основная озвучка субтитров через ElevenLabs **не требует ключа OpenAI**.
Необязательный радиоперевод и облачный эксперимент эмоций используют отдельный API;
для первого запуска оставьте их выключенными.

## 4. Запустите GameVoice

```powershell
work/venv/Scripts/python.exe outputs/GameVoice/subtitle_elevenlabs.py
```

1. Убедитесь, что в окне есть изображение с карты. Закройте OBS, если он занимает устройство.
2. В игре включите **русские субтитры, имена говорящих и фон под текстом**.
3. В поле «Размер субтитров» выберите соответствующий размер. Для начала удобнее средний.
4. При необходимости выделите зелёную область мышью: она должна охватывать все строки
   субтитров, в том числе третью, но не захватывать лишний интерфейс.
5. Выберите «Вывод звука» — колонки или наушники ПК. Начните с умеренной громкости.
6. Выберите доступный голос. Через «Голоса персонажей…» можно назначить его персонажу.
7. Включите «Озвучивать субтитры» и продолжите сцену с диалогом.

Для меньшего ожидания попробуйте Flash; v4 Turbo — баланс, v4 — приоритет качества.
Доступность моделей проверяется сервисом при настоящем запросе синтеза.
Цветной статус показывает результат реальных запросов, а не отдельной платной проверки.

Русская речь воспроизводится компьютером. Если оригинальные голоса одновременно
слышны из телевизора, настройте его громкость отдельно. Программа не умеет автоматически
удалять только английские голоса из всех игровых звуков.

## Что пока требует доработки

- Универсальный выбор карты и автоматическая проверка её режимов.
- Установка FFmpeg, OCR и первоначальное сохранение ключа через один мастер.
- Перенос фонового сборщика голосов: в нём пока есть пути и зависимости рабочего ПК автора.
  Не запускайте скрипты записи и очистки как обязательный шаг обычной озвучки.
- Пакеты образцов не включены в ZIP; публичный пакет пока не опубликован.

## Тесты и сборка для разработчиков

```powershell
work/venv/Scripts/python.exe tools/run_tests.py
work/venv/Scripts/python.exe -m pip install -r requirements-dev.txt
work/venv/Scripts/python.exe -m PyInstaller --noconfirm --distpath dist --workpath build work/GameVoice-ElevenLabs.spec
```

`tools/run_tests.py` запускает отобранные локальные проверки с временными настройками
и тестовыми ответами API. Внешние сетевые подключения блокируются. Некоторым другим
тестам в `work/` нужны локальные игровые изображения, которых нет в репозитории.
Сборка EXE не включает FFmpeg, русский OCR, ключи или голосовые пакеты и пока
не заменяет полноценный установщик. Для распространения внешних компонентов
потребуется учитывать их лицензии.
